# South Florida for skate. (ReSkate)

![South Florida](images/cover.jpg)

**South Florida by B-Row**, the Skater XL street map, ported to skate. through
[ReSkate](https://github.com/Dingo-Shenanigans/ReSkate).

Download it from Thunderstore (community `reskate`). This repository only holds the pictures and notes for
the release page.

![Map of South Florida](images/map.jpg)
